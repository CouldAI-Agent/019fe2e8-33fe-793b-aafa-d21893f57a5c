# Consortium Study App

Ek basic Flutter app jo consortium aur uske related topics ki study karne ke liye banai gayi hai. Isme alag-alag sections (Guidelines, Members, Case Studies, Reports) ko explore kiya ja sakta hai.

## Features
- **Dashboard**: Ek responsive grid layout jisme study topics list kiye gaye hain.
- **Cross-Platform**: Mobile, tablet aur desktop pe achhe se kaam karta hai.
- **Material 3**: Modern UI components aur themes.

## Kaise Run Karein
1. Dependencies install karein:
   ```sh
   flutter pub get
   ```
2. App ko run karein:
   ```sh
   flutter run
   ```
